What is Fantamatrimonio?
Fantamatrimonio is a playful prediction game where you compete with friends to guess who will get married next. Inspired by FantaSanremo, this web application lets you create leagues, bet on your friends' relationship outcomes, and track predictions in real-time.
​
Core Concept:
Select friends you think will get married soon
Make predictions about engagement and wedding dates
Earn points based on accuracy of your predictions
Compete on leaderboards with other players
Track who has the best intuition about their friends' love lives

Features:
RESTful API Architecture - Full REST API backend for all operations
Google OAuth Authentication - Secure login with Google accounts
League Management - Create and manage private leagues with invite codes
Real-time Predictions - Submit and track relationship milestone predictions
Point System - Automated scoring based on prediction accuracy
Live Leaderboards - Real-time ranking updates
Mobile Responsive - Progressive Web App design
API Documentation - Complete REST API for third-party integrations
